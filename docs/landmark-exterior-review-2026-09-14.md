## 证据和边界

- `sources/exteriors/landmarks/catalog.mjs` 记录轮廓 ID、建筑来源、材料、特征与各自范围；`source-manifest.json` 记录导出证据。
- 轮廓统一用米制东/南坐标，再整体等比缩放；OSM 周边采用相同变换，不分别拉伸两个方向。
- 部分高度、窗洞节奏、屋顶小构件位置仍为示意，不是测绘。米拉之家屋顶构件与阳台数量采用机构资料，逐个位置和雕塑形状不冒称精确。
- 古罗马广场、帕拉蒂尼山只表达有依据的遗存体量，不代表逐墙复原；未制作精确地形。米开朗基罗广场纪念像不是雕塑复制品，特雷维喷泉未制作人物群雕。
- 古埃尔公园已排除先前误选的学校旧楼，改用两座门房、百柱厅和自然广场对应轮廓。
- 保留圣彼得大教堂和圣彼得广场原有模型及独立街区视图：这两处仍未精确配准，不计入已完成融合的模型。
- 此轮不修订室内平面或补称室内资料缺口已经解决。默认 2D 和入口层规则不变。

## 验收

- 全套测试：72 个文件、1146 项通过。
- 组合检查：73 个非船体导览条目；60 项注册模型做三角面相交检查，11 项为地图区域，2 项为未配准分开展示。已融合模型未发现超过接触容差的穿插；另检查源周边建筑之间的重叠。
- 25 个新模型在桌面 1440px 和手机模拟 390px 下检查实际 WebGL 像素、完整取景、拖动、缩放、运行错误和页面横向溢出，50 个页面状态通过。

- 初始视角经过主体/周边网格遮挡采样与截图复核；调整角度，不删除真实邻楼。采样和截图不是“任意角度都无遮挡”的保证。
- 逐张检查了单体、街区组合、旋转后的桌面截图，以及手机截图。证据在 `work/landmark-exterior-qa/`。
- 本轮修改文件的严格 lint 和 TypeScript 检查通过。全库 lint 尚有未改文件 `scripts/complete-museum-context.mjs` 的既有未使用导入问题。

## 重建命令

1. `node scripts/build-landmark-exteriors.mjs`
2. `node scripts/build-exterior-context.mjs <slug...>`
3. `node scripts/compose-exterior-context.mjs <slug...>`
4. `npx tsx scripts/review-landmark-cameras.ts`
5. `npx vitest run --maxWorkers=2`
6. `node scripts/qa-landmark-exteriors.mjs`

GLB 和 SVG 回退均来自同一份网格；当前离线资源生成器会收录新模型目录。重新生成不等于自动发布。

## 西班牙台阶悬空修复

- 原因：原模型只将几条路径挤出为固定宽度薄台阶，没有生成已存在于 OSM 数据中的完整阶梯区域和三个平台；教堂抬高后也没有地面承托。
- 改为按 `w134400816` 的阶梯区域、`w1416143815` / `w54572036` / `w54572034` 的平台多边形和九段阶梯路径生成连贯踏步。踏步、平台、上层街道和教堂下方均具有落到共同基准面的实心承托。
- 平台高差 6.5 / 12 / 16 米、上层街道 22 米和教堂入口 24 米为可视化近似值，踏步数量和地形切面不是测绘复原；周边街区没有新增 DEM 地形。结构关系参考 [罗马旅游局的西班牙台阶说明](https://www.turismoroma.it/en/places/spanish-steps)。
- 默认视角调整至台阶下方一侧。本次只重建西班牙台阶及其街区组合，不改其他景点或室内地图。
- 新增区域覆盖、路径高差连接和 GLB 承托基准面回归测试。更新后全套 73 个测试文件、1149 项通过，生产构建、78 项组合审计、TypeScript 和修改文件严格 lint 通过。
- 桌面与手机模拟视图通过初始完整取景、实际像素、拖动、缩放与运行错误检查；另检查侧面、俯视截图。定向 QA 的 `report.json` 本次仅记录西班牙台阶的两个尺寸，不代表重新执行了全站 50 个状态。
