# Latest Guide Release: 2026-09-14

This release includes the accumulated local guide changes after `f69f6b3`.
It does not re-enable the rejected Florence exterior trial.

## Scope

- Local museum and landmark exteriors, OSM roads/buildings/walls/land, reviewed
  registrations, and the current overlap and coplanar-surface repairs.
- Updated collection interpretation, artwork viewing, guide navigation, visitor
  information, booking status, and offline download/retry controls.
- Indoor maps retain initial 2D, reviewed entry-floor selection, complete initial
  framing, and readable zoomed labels. Their source limitations remain visible.
- Florence retains its original church model, texture and OSM surroundings.
  `guideExteriorTrials` is empty. Remote models remain on the separate `/models/`
  trial page, which now has a directory export under the GitHub Pages base path.

## Release Repairs

The release review found that raised schematic indoor walls could bury entrance
markers, including Correr's entry. The marker lift now derives from the display
wall height. Source x/y locations and wall geometry are unchanged; occlusion by
other floors remains enforced. A regression test covers both cases.

Browser acceptance separates complete initial framing from zoomed reading and
explicit 3D selection. Glyph-pixel checks cover every label; one viewport capture
can verify multiple visible labels. Offline Vatican checks now exercise the
current local museum model and OSM composition instead of obsolete Braccio-only
controls. Deployment still requires the existing indoor-map acceptance gate.

## Validation

- TypeScript, lint, production build and 1,176 tests passed locally.
- 80 guide/core routes passed real Chromium offline reloads; no missing precache
  resources. The separate online model trial is not included in that promise.
- 240 whole-page cases passed at widths 1440, 1094 and 390.
- 42 indoor maps passed emulated touch drag, pinch, cancellation and floor taps.

- Florence, Sagrada Familia, St Mark's, Correr, Vatican Museums and Spanish Steps

  Served model/context hashes were compared with the local assets.
