# 欧洲文化导览 · 本地试用版

这是用于提前体验的版本，不代表全部景点制作完成。准确构建版本和文件校验记录见 `release.json` 与 `files.sha256.json`。本包没有推送到 GitHub，也不修改原开发项目。

## 打开

1. 解压整个压缩包，保持文件夹内容在一起。
2. 在 Mac 上双击 `Start.command`，浏览器会自动打开。
3. 使用过程中保持启动它的终端窗口打开。按 Control+C 停止服务。

本机需要 Node.js；当前制作电脑已具备。无需安装项目依赖、重新编译或登录账号。其他系统可在本文件夹执行 `node serve.mjs`，然后打开终端给出的地址。

默认地址为 `http://127.0.0.1:55911/europe-cultural-guide-2026/`。若端口被占用，会选择后续空闲端口，以终端显示为准。仅本机可访问，没有对局域网或公网开放。不能直接双击 `site/index.html`，那会绕过页面路由和离线缓存。

## 建议体验

- 首页城市顺序、逐日行程与景点索引。
- 梵蒂冈馆区总览的 2D / 3D 切换，圣彼得与西斯廷的视角定位。
- 乌菲兹、佛罗伦萨学院美术馆的连续藏品列表、筛选、详情、完整图片与缩放。
- 室内地图默认 2D 和核对过的入口楼层；楼层切换、房号、作品与房间联动。
- 比萨斜塔、叹息桥的新外观及局部视角。
- 手机宽度下的布局、现场导览与离线状态。

## 离线

全部网页、图片和地图资源已经在本包中，启动本地服务无需联网。网站另有浏览器离线缓存：首次打开后等待离线准备完成，再断网并刷新、打开此前没看过的景点。缓存与浏览器、端口绑定；换浏览器或端口需重新准备。不要用隐私模式验证长期保存。

本地服务器启动和浏览器缓存是两回事；日常试用仍建议保持启动窗口打开。此版本不声称已经通过实体手机、Safari 或实体设备 30 FPS 验收。
