# 梵蒂冈博物馆 · 离线导览

用于 GitHub Pages 的纯静态离线导览。仅包含公开运行所需的页面、代码、图片、字体和安装文件，不包含登录数据、浏览器存档或原始工作文件。

用 iPhone Safari 打开部署地址，添加到主屏幕后，保持联网从新图标打开，等待页面右下角显示「离线已就绪」，再断网使用。首次完整下载约 35 MB。

官网、购票及其他外部链接仍需联网。iOS 清理网站数据或回收存储后可能需要重新下载；出行前请做一次断网重开检查。

发布来源为 `main` 分支根目录；`.nojekyll` 保留原始文件。此仓库不使用后端、数据库或运行时密钥。修改运行文件时，必须同时重新生成 `precache.json` 和 `sw.js` 内的完整性清单。
