# Online Model Trial Archive

The former `/models/` route is not part of the production website. Its page is
preserved here with the existing preview components and source/license catalog.
Those modules are not imported by production routes. Do not put the route back
under `app/` or wire it into `GuideExterior` without explicit user approval.

This archive does not contain the local production model assets. Keep
`public/models/`, their fallback images, textures, OSM context, and attributions.
